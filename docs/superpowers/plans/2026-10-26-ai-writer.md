# AI Writer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Notion's inline AI Writer in Nobsidian: Claude edits, continues, summarizes, translates and explains text in the page you are on, with your own Anthropic API key.

**Architecture:** The main process owns the key (encrypted with `safeStorage`), calls Claude through the official SDK and streams results to the renderer over typed IPC events; it also keeps a monthly usage ledger.
In the editor, a ProseMirror plugin shows each result as an in-place diff that never reaches the Markdown file until it is accepted, as one undo step.
A Settings window in Notion's layout holds the key, the model and the month's spend; e2e tests talk to a fake Anthropic server that speaks the real streaming protocol.

**Tech Stack:** Electron 44, React 19, TypeScript 7, BlockNote 0.56, ProseMirror, zustand, `@anthropic-ai/sdk` 1.3, Vitest 5 with `happy-dom` for editor tests, Playwright 1.64.

**Spec:** `docs/superpowers/specs/2026-10-26-ai-writer-design.md`

This plan was written from a prototype: every code block below compiled, passed lint and its tests, and each task's new tests failed on the previous task's code.

## Review Focus

- Quitting the app while Claude is writing: the file keeps the page as it was, with the user's own typing (Task 6 test "quitting while Claude writes keeps the page as it was").
- Claude wraps its whole answer in a ```` ```markdown ```` fence: the fence is taken off rather than becoming a code block (Task 3 test "lose a code fence wrapped around the whole answer").
- Claude's answer contains an image: it is left out, so neither the page nor the popup ever loads a remote file (Task 3 test "never bring images or files into the page").
- An inline edit inside a heading or a to-do keeps the block a heading or a checked to-do (Task 3 test "keep a heading or a to-do what it is after an inline edit").
- A page over 100,000 characters: only the text centred on the selection is sent, with each cut marked (Task 1 test "keeps the text around the selection of a huge page").

```ts
import Anthropic from '@anthropic-ai/sdk'
import { expect, it } from 'vitest'
import { aiError } from './errors'

const status = (code: number, body: object, headers: Record<string, string> = {}): Error =>
  Anthropic.APIError.generate(code, body, undefined, new Headers(headers))

it('names a rejected key', () => {
  expect(
    aiError(
      status(401, {
        type: 'error',
        error: { type: 'authentication_error', message: 'invalid x-api-key' }
      })
    )
  ).toEqual({
    kind: 'auth',
    message: 'Your API key was rejected.'
  })
})

it('says when to retry after a rate limit', () => {
  const body = { type: 'error', error: { type: 'rate_limit_error', message: 'slow down' } }
  expect(aiError(status(429, body, { 'retry-after': '12' })).message).toBe(
    'Too many requests right now. Try again in 12 seconds.'
  )
  expect(aiError(status(429, body)).message).toBe(
    'Too many requests right now. Try again in a moment.'
  )
})

it('treats overloaded and server errors as busy, with or without a status', () => {
  const overloaded = { type: 'error', error: { type: 'overloaded_error', message: 'Overloaded' } }
  expect(aiError(status(529, overloaded)).kind).toBe('busy')
  expect(
    aiError(status(500, { type: 'error', error: { type: 'api_error', message: 'x' } })).kind
  ).toBe('busy')
  // How the SDK reports an error event in the middle of a stream.
  const inStream = new Anthropic.APIError(
    undefined,
    overloaded,
    undefined,
    new Headers(),
    'overloaded_error'
  )
  expect(aiError(inStream).kind).toBe('busy')
})

it("passes other request errors through in Anthropic's words", () => {
  const body = {
    type: 'error',
    error: { type: 'invalid_request_error', message: 'Your credit balance is too low.' }
  }
  expect(aiError(status(400, body))).toEqual({
    kind: 'request',
    message: 'Anthropic said: Your credit balance is too low.'
  })
})

it('treats connection failures, timeouts and anything else as the network', () => {
  const network = "Can't reach Anthropic. Check your internet connection."
  expect(aiError(new Anthropic.APIConnectionError({ message: 'fetch failed' })).message).toBe(
    network
  )
  expect(aiError(new Anthropic.APIConnectionTimeoutError()).kind).toBe('network')
  expect(aiError(new TypeError('socket hang up')).kind).toBe('network')
})
```

```ts
import Anthropic from '@anthropic-ai/sdk'
import type { AiError } from '../../shared/ai'

const NETWORK = "Can't reach Anthropic. Check your internet connection."

function retryAfterSeconds(headers: Headers | undefined): number | null {
  const value = Number(headers?.get('retry-after'))
  return Number.isFinite(value) && value > 0 ? Math.ceil(value) : null
}

function apiMessage(error: InstanceType<typeof Anthropic.APIError>): string {
  const body = error.error as { error?: { message?: unknown } } | undefined
  const message = body?.error?.message
  return typeof message === 'string' && message ? message : error.message
}

export function aiError(error: unknown): AiError {
  if (error instanceof Anthropic.AuthenticationError) {
    return { kind: 'auth', message: 'Your API key was rejected.' }
  }
  if (error instanceof Anthropic.RateLimitError) {
    const seconds = retryAfterSeconds(error.headers)
    return {
      kind: 'rate',
      message: seconds
        ? `Too many requests right now. Try again in ${seconds} seconds.`
        : 'Too many requests right now. Try again in a moment.'
    }
  }
  if (error instanceof Anthropic.APIConnectionError) return { kind: 'network', message: NETWORK }
  if (error instanceof Anthropic.APIError) {
    // Errors sent inside a stream have a type but no status.
    const busy =
      (typeof error.status === 'number' && error.status >= 500) ||
      error.type === 'overloaded_error' ||
      error.type === 'api_error'
    if (busy) return { kind: 'busy', message: 'Claude is busy right now. Try again in a moment.' }
    return { kind: 'request', message: `Anthropic said: ${apiMessage(error)}` }
  }
  return { kind: 'network', message: NETWORK }
}
```

```ts
import type Anthropic from '@anthropic-ai/sdk'
import {
  CURSOR,
  modeOf,
  SELECTION_START,
  skill as skillById,
  type AiMode,
  type AiStart
} from '../../shared/ai'

type MessageParam = Anthropic.Beta.Messages.BetaMessageParam
type Tool = Anthropic.Beta.Messages.BetaTool

export const PAGE_LIMIT = 100_000

// Byte-identical on every request, so it heads the cached prefix.
export const SYSTEM_PROMPT = [
  'You are the writing assistant inside Nobsidian, a note-taking app.',
  "The user's current page is given in Markdown inside <page> tags.",
  '⟦selection⟧ and ⟦/selection⟧ mark the text the user selected, and ⟦cursor⟧ marks where the cursor is.',
  'These markers are not part of the page: never write them.',
  '',
  'Follow the instruction and give the result only: no preamble, no explanation, no closing remarks, and no code fence around the whole result.',
  'Write Markdown in the style of the page, and keep links, page links and formatting.',
  'Keep the language of the text unless asked to translate.',
  'Never invent facts, names, numbers or dates that the page does not support.',
  'A result for the selection replaces only the selected text, so do not repeat the text around it.',
  'A result for the cursor is inserted there, so do not repeat the page.'
].join('\n')

const MARKDOWN_INPUT = {
  type: 'object' as const,
  properties: { markdown: { type: 'string', description: 'The result, in Markdown.' } },
  required: ['markdown'],
  additionalProperties: false
}

const tool = (name: AiMode, description: string): Tool => ({
  name,
  description,
  input_schema: MARKDOWN_INPUT,
  strict: true,
  eager_input_streaming: true
})

export const TOOLS: Record<AiMode, Tool> = {
  edit: tool(
    'edit',
    'Replace the selected text with this Markdown. Use it when the user asks to change, rewrite, translate or format the selection.'
  ),
  insert: tool(
    'insert',
    'Insert this Markdown at the cursor. Use it when the user asks you to write something.'
  ),
  reply: tool(
    'reply',
    'Answer the user in the AI popup without changing the page. Use it for questions about the page or the selection.'
  )
}

/** Keeps PAGE_LIMIT characters centred on the selection or cursor, marking each cut. */
export function trimPage(markdown: string): string {
  if (markdown.length <= PAGE_LIMIT) return markdown
  const marker = [SELECTION_START, CURSOR].map((m) => markdown.indexOf(m)).find((i) => i >= 0)
  const center = marker ?? 0
  const start = Math.max(0, Math.min(center - PAGE_LIMIT / 2, markdown.length - PAGE_LIMIT))
  const end = start + PAGE_LIMIT
  return (
    (start > 0 ? '[…]\n' : '') + markdown.slice(start, end) + (end < markdown.length ? '\n[…]' : '')
  )
}

function escapeAttr(value: string): string {
  return value.replace(/&/g, '&amp;').replace(/"/g, '&quot;').replace(/</g, '&lt;')
}

/** The instruction for a new request: a skill's own, a finished prefill, or free text. */
export function instructionText(start: AiStart): string {
  const typed = start.instruction?.trim() ?? ''
  if (!start.skill) return typed
  const s = skillById(start.skill)
  if (!s.prefill) return s.instruction
  if (s.kind === 'editPage')
    return `${typed}. The result replaces the whole page, so write all of it.`
  return `${typed}. Apply it to the selection.`
}

/** Free text lets Claude choose between changing the page and replying. */
export function toolsFor(start: AiStart): Tool[] | null {
  if (start.skill) return null
  return [start.selection ? TOOLS.edit : TOOLS.insert, TOOLS.reply]
}

export function modeFor(start: AiStart): AiMode | null {
  return start.skill ? modeOf(skillById(start.skill).kind) : null
}

export function firstMessage(start: AiStart): MessageParam {
  const page = `<page title="${escapeAttr(start.title)}">\n${trimPage(start.markdown)}\n</page>`
  const tools = toolsFor(start)
  const text = tools
    ? `${instructionText(start)}\n\nCall exactly one of the tools ${tools.map((t) => t.name).join(' or ')}.`
    : instructionText(start)
  return {
    role: 'user',
    content: [
      { type: 'text', text: page, cache_control: { type: 'ephemeral' } },
      { type: 'text', text }
    ]
  }
}

/** A follow-up after `previous`, Claude's last turn, which is sent back unchanged. */
export function followUpMessage(
  previous: Anthropic.Beta.Messages.BetaContentBlock[],
  text: string
): MessageParam {
  const results = previous.flatMap((block) =>
    block.type === 'tool_use'
      ? [{ type: 'tool_result' as const, tool_use_id: block.id, content: 'Shown to the user.' }]
      : []
  )
  return {
    role: 'user',
    content: [
      ...results,
      {
        type: 'text',
        text: `Revise your last result: ${text.trim()}\nGive the whole revised result.`
      }
    ]
  }
```

```ts
  inputTokens: number

  cacheReadTokens: number

export function costOf(model: string, usage: Usage): number {
  const price = PRICES[model] ?? UNKNOWN
  const tokens =
    usage.input_tokens * price.input +
    (usage.cache_creation_input_tokens ?? 0) * price.cacheWrite +
    (usage.cache_read_input_tokens ?? 0) * price.cacheRead +
    usage.output_tokens * price.output
  return tokens / 1_000_000
}

export function monthKey(date: Date): string {
  return `${date.getFullYear()}-${String(date.getMonth() + 1).padStart(2, '0')}`

const EMPTY: MonthUsage = {
  requests: 0,
  inputTokens: 0,
  outputTokens: 0,
  cacheWriteTokens: 0,
  cacheReadTokens: 0,
  dollars: 0

/** Token counts and dollars per month, kept on this Mac. */
export class UsageLedger {
  private months: Record<string, MonthUsage> | null = null

  constructor(private readonly file: string) {}

  private async load(): Promise<Record<string, MonthUsage>> {
    if (this.months) return this.months
    try {
      this.months = JSON.parse(await readFile(this.file, 'utf8')) as Record<string, MonthUsage>
    } catch {
      this.months = {}
    }
    return this.months
  }

  async month(date = new Date()): Promise<MonthUsage> {
    return (await this.load())[monthKey(date)] ?? { ...EMPTY }
  }

  async add(model: string, usage: Usage, date = new Date()): Promise<void> {
    const months = await this.load()
    const key = monthKey(date)
    const m = months[key] ?? { ...EMPTY }
    months[key] = {
      requests: m.requests + 1,
      inputTokens: m.inputTokens + usage.input_tokens,
      outputTokens: m.outputTokens + usage.output_tokens,
      cacheWriteTokens: m.cacheWriteTokens + (usage.cache_creation_input_tokens ?? 0),
      cacheReadTokens: m.cacheReadTokens + (usage.cache_read_input_tokens ?? 0),
      dollars: m.dollars + costOf(model, usage)
    }
    await mkdir(dirname(this.file), { recursive: true })
    await writeFileAtomic(this.file, JSON.stringify(months, null, 2) + '\n')
  }
```

```ts
import { createServer, type IncomingMessage, type Server, type ServerResponse } from 'node:http'
import type { AddressInfo } from 'node:net'

export const GOOD_KEY = 'sk-ant-api03-test-key-a1b2'

/** One scripted answer to POST /v1/messages. */
export interface FakeReply {
  /** Streamed as a text block. */
  text?: string
  /** Streamed as a tool call whose input is { markdown }. */
  tool?: { name: string; markdown: string }
  /** How many pieces the text or tool input is cut into. */
  chunks?: number
  /** Pause before each piece, in milliseconds. */
  delayMs?: number
  /** Stop after the first piece until release() is called. */
  hold?: boolean
  /** Close the connection after the first piece. */
  drop?: boolean
  /** Answer with this HTTP status and an error body instead of a stream. */
  status?: number
  errorType?: string
  errorMessage?: string
  retryAfter?: number
  /** Send an error event after the first piece. */
  streamError?: string
  stopReason?: 'end_turn' | 'max_tokens' | 'refusal' | 'tool_use'
  model?: string
  usage?: { input_tokens: number; output_tokens: number }
}

export interface RecordedRequest {
  method: string
  path: string
  headers: IncomingMessage['headers']
  body: Record<string, unknown> | null
}

const ERROR_TYPES: Record<number, string> = {
  400: 'invalid_request_error',
  401: 'authentication_error',
  403: 'permission_error',
  429: 'rate_limit_error',
  500: 'api_error',
  529: 'overloaded_error'
}

function pieces(text: string, count: number): string[] {
  const size = Math.max(1, Math.ceil(text.length / count))
  const out: string[] = []
  for (let i = 0; i < text.length; i += size) out.push(text.slice(i, i + size))
  return out.length ? out : ['']
}

const sleep = (ms: number): Promise<void> => new Promise((r) => setTimeout(r, ms))

/** A local stand-in for api.anthropic.com that speaks the real streaming protocol. */
export class FakeAnthropic {
  readonly requests: RecordedRequest[] = []
  private queue: FakeReply[] = []
  private releases: (() => void)[] = []
  private open = new Set<ServerResponse>()

  private constructor(
    private readonly server: Server,
    readonly url: string
  ) {}

  static async start(): Promise<FakeAnthropic> {
    let fake: FakeAnthropic | null = null
    const server = createServer((req, res) => void fake!.handle(req, res))
    await new Promise<void>((resolve) => server.listen(0, '127.0.0.1', resolve))
    const { port } = server.address() as AddressInfo
    fake = new FakeAnthropic(server, `http://127.0.0.1:${port}`)
    return fake
  }

  /** Queues answers for the next requests; once they run out, each answer is "OK.". */
  reply(...replies: FakeReply[]): void {
    this.queue.push(...replies)
  }

  /** Lets held streams finish. */
  release(): void {
    for (const release of this.releases.splice(0)) release()
  }

  /** The bodies of the message requests so far. */
  messages(): Record<string, unknown>[] {
    return this.requests.filter((r) => r.path === '/v1/messages').map((r) => r.body!)
  }

  async close(): Promise<void> {
    this.release()
    for (const res of this.open) res.destroy()
    await new Promise<void>((resolve) => this.server.close(() => resolve()))
  }

  private async handle(req: IncomingMessage, res: ServerResponse): Promise<void> {
    const chunks: Buffer[] = []
    for await (const chunk of req) chunks.push(chunk as Buffer)
    const raw = Buffer.concat(chunks).toString()
    const path = (req.url ?? '').split('?')[0]
    this.requests.push({
      method: req.method ?? '',
      path,
      headers: req.headers,
      body: raw ? (JSON.parse(raw) as Record<string, unknown>) : null
    })
    // The SDK sends the key as a bearer token; older clients use x-api-key.
    const key = req.headers['x-api-key'] ?? req.headers.authorization?.replace(/^Bearer /, '')
    if (key !== GOOD_KEY) return this.error(res, { status: 401, errorMessage: 'invalid x-api-key' })
    if (path === '/v1/models') {
      res.writeHead(200, { 'content-type': 'application/json' })
      res.end(JSON.stringify({ data: [], has_more: false, first_id: null, last_id: null }))
      return
    }
    if (path !== '/v1/messages') return this.error(res, { status: 404, errorMessage: 'not found' })
    const reply = this.queue.shift() ?? { text: 'OK.' }
    if (reply.status) return this.error(res, reply)
    await this.stream(res, reply, (this.requests.at(-1)!.body!.model as string) ?? 'claude')
  }

  private error(res: ServerResponse, reply: FakeReply): void {
    const status = reply.status ?? 500
    const headers: Record<string, string> = { 'content-type': 'application/json' }
    if (reply.retryAfter) headers['retry-after'] = String(reply.retryAfter)
    res.writeHead(status, headers)
    res.end(
      JSON.stringify({
        type: 'error',
        error: {
          type: reply.errorType ?? ERROR_TYPES[status] ?? 'api_error',
          message: reply.errorMessage ?? 'Something went wrong.'
        }
      })
    )
  }

  private async stream(res: ServerResponse, reply: FakeReply, model: string): Promise<void> {
    this.open.add(res)
    res.on('close', () => this.open.delete(res))
    res.writeHead(200, { 'content-type': 'text/event-stream', 'cache-control': 'no-cache' })
    const event = (type: string, data: object): void => {
      res.write(`event: ${type}\ndata: ${JSON.stringify({ type, ...data })}\n\n`)
    }
    const usage = reply.usage ?? { input_tokens: 2300, output_tokens: 450 }
    event('message_start', {
      message: {
        id: 'msg_fake',
        type: 'message',
        role: 'assistant',
        model: reply.model ?? model,
        content: [],
        stop_reason: null,
        stop_sequence: null,
        usage: { input_tokens: usage.input_tokens, output_tokens: 1 }
      }
    })
    const tool = reply.tool
    event('content_block_start', {
      index: 0,
      content_block: tool
        ? { type: 'tool_use', id: 'toolu_fake', name: tool.name, input: {} }
        : { type: 'text', text: '' }
    })
    const body = tool ? JSON.stringify({ markdown: tool.markdown }) : (reply.text ?? '')
    const parts = pieces(body, reply.chunks ?? 4)
    for (const [i, part] of parts.entries()) {
      if (reply.delayMs) await sleep(reply.delayMs)
      if (res.destroyed) return
      event('content_block_delta', {
        index: 0,
        delta: tool
          ? { type: 'input_json_delta', partial_json: part }
          : { type: 'text_delta', text: part }
      })
      if (i > 0) continue
      if (reply.hold) await new Promise<void>((resolve) => this.releases.push(resolve))
      if (res.destroyed) return
      if (reply.drop) return void res.destroy()
      if (reply.streamError) {
        event('error', {
          error: { type: reply.streamError, message: 'Overloaded' }
        })
        return void res.end()
      }
    }
    event('content_block_stop', { index: 0 })
    event('message_delta', {
      delta: {
        stop_reason: reply.stopReason ?? (tool ? 'tool_use' : 'end_turn'),
        stop_sequence: null
      },
      usage: { output_tokens: usage.output_tokens }
    })
    event('message_stop', {})
    res.end()
  }
}
```

```ts
import { chmod, mkdir, readFile, rm } from 'node:fs/promises'
import { dirname } from 'node:path'
import { writeFileAtomic } from '../workspace/fs-utils'

export interface KeyCodec {
  available(): boolean
  encrypt(text: string): Buffer
  decrypt(data: Buffer): string
}

/** Shows enough of a key to recognise it, and nothing that would let anyone use it. */
export function keyHint(key: string): string {
  const tail = key.slice(-4)
  return key.startsWith('sk-ant-') ? `sk-ant-…${tail}` : `…${tail}`
}

/** The Anthropic API key, encrypted at rest; it never leaves the main process. */
export class KeyStore {
  private cached: string | null | undefined

  constructor(
    private readonly file: string,
    private readonly codec: KeyCodec
  ) {}

  available(): boolean {
    return this.codec.available()
  }

  async get(): Promise<string | null> {
    if (this.cached !== undefined) return this.cached
    try {
      this.cached = this.codec.decrypt(await readFile(this.file))
    } catch {
      this.cached = null
    }
    return this.cached
  }

  async set(key: string): Promise<void> {
    if (!this.codec.available()) throw new Error('Encryption is not available on this Mac.')
    await mkdir(dirname(this.file), { recursive: true })
    await writeFileAtomic(this.file, this.codec.encrypt(key))
    await chmod(this.file, 0o600)
    this.cached = key
  }

  async clear(): Promise<void> {
    await rm(this.file, { force: true })
    this.cached = null
  }
}
```

```ts
  idleTimeoutMs?: number
}

export class AiService {

  private running = new Map<string, AbortController>()
  private readonly client: (key: string) => Anthropic

  constructor(private readonly options: AiServiceOptions) {
    this.client = options.client ?? createClient
  }

  async status(): Promise<AiStatus> {
    const key = await this.options.keys.get()
    const month = await this.options.usage.month()
    return {
      hasKey: key !== null,
      keyHint: key ? keyHint(key) : null,
      encryptionAvailable: this.options.keys.available(),
      month: { requests: month.requests, dollars: month.dollars }
    }
  }

  /** Saves a key only after Anthropic accepts it. */
  async setKey(raw: string): Promise<AiKeyResult> {
    const key = raw.trim()
    if (!key) return { ok: false, error: 'Paste your API key first.' }
    if (!this.options.keys.available()) {
      return { ok: false, error: "This Mac can't store the key safely, so it was not saved." }
    }
    try {
      await this.client(key).models.list({ limit: 1 })
    } catch (err) {
      const error = aiError(err)
      return {
        ok: false,
        error: error.kind === 'auth' ? 'Anthropic rejected this key.' : error.message
      }
    }
    await this.options.keys.set(key)

  }

    await this.options.keys.clear()
  }

      idle = setTimeout(() => {
        timedOut = true
        controller.abort()

          mode = name
          toolCalled = true
        }

    stream.on('text', (_delta, text) => {
      if (!toolCalled) send('ai:delta', { requestId, mode, text })

      clearTimeout(idle)
      this.running.delete(requestId)
```

### Task 3: The pending change in the editor

A BlockNote extension holds a result the Writer shows but has not applied: where it goes (inline text, blocks, below, at the cursor, or the whole page body), what it removes and adds, and decorations for both.
Each render deletes the previous result and inserts the new one, so positions never drift and the undo history from before the Writer survives (replacing the whole document wiped it in the prototype); Accept restores the page and applies the result as one undoable step, and Undo leaves nothing behind.

````ts
import { blockToNode, createExtension, type BlockNoteEditor } from '@blocknote/core'
import { Fragment, type Node, type ResolvedPos } from 'prosemirror-model'
import { Plugin, PluginKey, type EditorState } from 'prosemirror-state'
import { Decoration, DecorationSet } from 'prosemirror-view'
import { markdownToBlocks } from '@shared/core/parse'
import type { Block } from '@shared/core/blocks'

// eslint-disable-next-line @typescript-eslint/no-explicit-any
type AnyEditor = BlockNoteEditor<any, any, any>

export type Placement = 'edit' | 'insertBelow' | 'insertAtCursor' | 'editPage'

interface Range {
  from: number
  to: number
}

/**
 * A change the Writer has shown but not applied. The page itself is untouched apart from the
 * added content, which sits after anything it replaces, so these positions never move.
 */
export interface Pending {
  /** Text inside one block that a single paragraph replaces in place. */
  inline: Range | null
  /** Blocks replaced when the result is not inline; null when the result is only inserted. */
  blocks: Range | null
  /** Where block results go: after `blocks`, or after the cursor's block. */
  insertAt: number
  /** Whether anything has been shown, whether it is inline, and its size in the document. */
  rendered: boolean
  isInline: boolean
  addedSize: number
}

const key = new PluginKey<Pending | null>('nbAiPending')

export function pendingOf(state: EditorState): Pending | null {
  return key.getState(state) ?? null
}

export function hasPending(editor: AnyEditor): boolean {
  return pendingOf(editor.prosemirrorState) !== null
}

function containerDepth($pos: ResolvedPos): number {
  for (let d = $pos.depth; d > 0; d--) if ($pos.node(d).type.name === 'blockContainer') return d
  return -1
}

/** The run of sibling blocks that holds both ends of the selection. */
function touchedBlocks(state: EditorState): Range {
  const { $from, $to } = state.selection
  const range = $from.blockRange($to, (node) => node.type.name === 'blockGroup')
  if (range) return { from: range.start, to: range.end }
  const d = containerDepth($from)
  return { from: $from.before(d), to: $from.after(d) }
}

function blockRange(doc: Node, ids: string[]): Range | null {
  let from = -1
  let to = -1
  doc.descendants((node, pos) => {
    if (node.type.name !== 'blockContainer') return true
    if (ids.includes(node.attrs.id)) {
      if (from === -1) from = pos
      to = pos + node.nodeSize
      return false
    }
    return true
  })
  return from === -1 ? null : { from, to }
}

/** Where a result for `placement` goes, given the selection or the selected blocks. */
export function placementRanges(
  state: EditorState,
  placement: Placement,
  selectedBlocks: string[] = []
): Omit<Pending, 'rendered' | 'isInline' | 'addedSize'> {
  const doc = state.doc
  if (placement === 'editPage') {
    const end = 1 + doc.firstChild!.content.size
    return { inline: null, blocks: { from: 1, to: end }, insertAt: end }
  }
  const { $from, $to, empty } = state.selection
  const picked = selectedBlocks.length ? blockRange(doc, selectedBlocks) : null
  const touched = picked ?? touchedBlocks(state)
  if (placement === 'insertBelow') return { inline: null, blocks: null, insertAt: touched.to }
  if (placement === 'insertAtCursor') {
    const d = containerDepth($from)
    const container = $from.node(d)
    const cursorBlock = { from: $from.before(d), to: $from.after(d) }
    const content = container.firstChild!
    const blank =
      container.childCount === 1 && content.type.name === 'paragraph' && content.content.size === 0
    return { inline: null, blocks: blank ? cursorBlock : null, insertAt: cursorBlock.to }
  }
  const inline =
    !picked && !empty && $from.parent === $to.parent && $from.parent.isTextblock
      ? { from: $from.pos, to: $to.pos }
      : null
  return { inline, blocks: touched, insertAt: touched.to }
}

/** Starts a pending change; nothing is shown until the first render. */
export function beginPending(
  editor: AnyEditor,
  placement: Placement,
  selectedBlocks: string[] = []
): void {
  const pending: Pending = {
    ...placementRanges(editor.prosemirrorState, placement, selectedBlocks),
    rendered: false,
    isInline: false,
    addedSize: 0
  }
  editor.transact((tr) => {
    tr.setMeta('addToHistory', false)
    tr.setMeta(key, pending)
  })
}

function inlineFragment(editor: AnyEditor, blocks: Block[]): Fragment {
  const content = blocks[0]?.type === 'paragraph' ? blocks[0].content : []
  const paragraph = blockToNode({ type: 'paragraph', content } as never, editor.pmSchema)
  return paragraph.firstChild!.content
}

function blockFragment(editor: AnyEditor, blocks: Block[]): Fragment {
  return Fragment.from(blocks.map((block) => blockToNode(block as never, editor.pmSchema)))
}

const MEDIA = new Set(['image', 'video', 'audio', 'file', 'drawing'])
const WRAPPING_FENCE = /^```(?:markdown|md)?\n([\s\S]*?)\n?```\s*$/

/**
 * Claude's Markdown as blocks for the page. A fence around the whole answer is taken off, and
 * media is left out, so an answer can never make the page load a remote file.
 */
export function resultBlocks(markdown: string): Block[] {
  const fenced = WRAPPING_FENCE.exec(markdown.trim())
  const strip = (blocks: Block[]): Block[] =>
    blocks
      .filter((b) => !MEDIA.has(b.type))
      .map((b) => ({ ...b, children: strip(b.children) }) as Block)
  return strip(markdownToBlocks(fenced ? fenced[1] : markdown))
}

function fitsInline(blocks: Block[]): boolean {
  if (blocks.length === 0) return true
  return blocks.length === 1 && blocks[0].type === 'paragraph' && blocks[0].children.length === 0
}

/** Shows `markdown` as the pending result, in place of the previous one. */
export function renderPending(editor: AnyEditor, markdown: string): void {
  const pending = pendingOf(editor.prosemirrorState)
  if (!pending) return
  const blocks = resultBlocks(markdown)
  const isInline = pending.inline !== null && fitsInline(blocks)
  const fragment = isInline ? inlineFragment(editor, blocks) : blockFragment(editor, blocks)
  const at = isInline ? pending.inline!.to : pending.insertAt
  const { added } = pendingRanges(pending)
  // Small steps rather than a whole-document swap, so the undo history before the Writer survives.
  editor.transact((tr) => {
    tr.setMeta('addToHistory', false)
    tr.delete(added.from, added.to)
    if (fragment.size) tr.insert(at, fragment)
    tr.setMeta(key, { ...pending, rendered: true, isInline, addedSize: fragment.size })
  })
}

/** The ranges the current render shows as removed and as added. */
export function pendingRanges(pending: Pending): { removed: Range | null; added: Range } {
  const removed = pending.isInline ? pending.inline : pending.blocks
  const at = pending.isInline ? pending.inline!.to : pending.insertAt
  return { removed, added: { from: at, to: at + pending.addedSize } }
}

function restore(editor: AnyEditor, pending: Pending): void {
  const { added } = pendingRanges(pending)
  editor.transact((tr) => {
    tr.setMeta('addToHistory', false)
    tr.delete(added.from, added.to)
    tr.setMeta(key, null)
  })
}

/** Puts the page back as it was; the Writer leaves no trace, not even in undo history. */
export function undoPending(editor: AnyEditor): void {
  const pending = pendingOf(editor.prosemirrorState)
  if (pending) restore(editor, pending)
}

/** Applies the result as a single undoable change. */
export function acceptPending(editor: AnyEditor): void {
  const pending = pendingOf(editor.prosemirrorState)
  if (!pending) return
  if (!pending.rendered) return undoPending(editor)
  const { removed, added } = pendingRanges(pending)
  const content = editor.prosemirrorState.doc.slice(added.from, added.to).content
  restore(editor, pending)
  editor.transact((tr) => {
    // A replaced page body must keep at least one block.
    const fill =
      content.size === 0 && removed && !pending.isInline && removed.from === 1
        ? Fragment.from(blockToNode({ type: 'paragraph' }, editor.pmSchema))
        : content
    if (removed) tr.replaceWith(removed.from, removed.to, fill)
    else if (fill.size) tr.insert(pending.insertAt, fill)
  })
}

function decorations(state: EditorState): DecorationSet | null {
  const pending = pendingOf(state)
  if (!pending) return null
  const { removed, added } = pendingRanges(pending)
  const out: Decoration[] = []
  const mark = (range: Range, kind: 'removed' | 'added'): void => {
    if (range.from === range.to) return
    if (pending.isInline) {
      out.push(Decoration.inline(range.from, range.to, { class: `nb-ai-${kind}` }))
      return
    }
    state.doc.nodesBetween(range.from, range.to, (node, pos) => {
      if (node.type.name !== 'blockContainer') return true
      if (pos >= range.from && pos + node.nodeSize <= range.to) {
        out.push(Decoration.node(pos, pos + node.nodeSize, { class: `nb-ai-${kind}-block` }))
      }
      return false
    })
  }
  if (removed) mark(removed, 'removed')
  mark(added, 'added')
  return DecorationSet.create(state.doc, out)
}

export const aiPending = createExtension({
  key: 'nbAiPending',
  prosemirrorPlugins: [
    new Plugin<Pending | null>({
      key,
      state: {
        init: () => null,
        apply: (tr, value) => {
          const next = tr.getMeta(key) as Pending | null | undefined
          return next === undefined ? value : next
        }
      },
      props: { decorations }
    })
  ]
})
````

```tsx
import { useState } from 'react'
import { useAi } from './aiStore'

/** Pasting and checking a key, or showing the one that is saved. */
export function KeyField({ onSaved }: { onSaved?: () => void }): React.JSX.Element {
  const status = useAi((s) => s.status)
  const [key, setKey] = useState('')
  const [state, setState] = useState<
    { kind: 'idle' } | { kind: 'checking' } | { kind: 'saved' } | { kind: 'error'; message: string }
  >({ kind: 'idle' })

  if (status && !status.encryptionAvailable) {
    return (
      <div className="settings-key-note">
        This Mac can&apos;t store the key safely, so AI can&apos;t be set up.
      </div>
    )
  }
  if (status?.hasKey) {
    return (
      <div className="settings-key">
        <span className="settings-key-hint">{status.keyHint}</span>
        {state.kind === 'saved' && <span className="settings-key-ok">✓ Key works</span>}
        <button
          type="button"
          className="button-secondary settings-button"
          onClick={() => {
            setState({ kind: 'idle' })
            void useAi.getState().clearKey()
          }}
        >
          Remove
        </button>
      </div>
    )
  }
  const save = async (): Promise<void> => {
    setState({ kind: 'checking' })
    const result = await useAi.getState().setKey(key)
    if (!result.ok) return setState({ kind: 'error', message: result.error })
    setKey('')
    setState({ kind: 'saved' })
    onSaved?.()
  }
  return (
    <div className="settings-key-entry">
      <form
        className="settings-key"
        onSubmit={(e) => {
          e.preventDefault()
          if (key.trim() && state.kind !== 'checking') void save()
        }}
      >
        <input
          type="password"
          className="settings-input"
          aria-label="Anthropic API key"
          placeholder="Paste your API key"
          autoComplete="off"
          spellCheck={false}
          value={key}
          onChange={(e) => {
            setKey(e.target.value)
            if (state.kind === 'error') setState({ kind: 'idle' })
          }}
        />
        <button
          type="submit"
          className="button-primary settings-button"
          disabled={!key.trim() || state.kind === 'checking'}
        >
          {state.kind === 'checking' ? 'Checking…' : 'Save'}
        </button>
      </form>
      {state.kind === 'error' && (
        <div className="settings-key-error" role="alert">
          {state.message}
        </div>
      )}
    </div>
  )
}
```

```ts
import { create } from 'zustand'
import type { AiKeyResult, AiStatus } from '@shared/ai'

const api = window.api

interface AiState {
  /** Null until the main process has answered. */
  status: AiStatus | null
  online: boolean
  refresh: () => Promise<void>
  setKey: (key: string) => Promise<AiKeyResult>
  clearKey: () => Promise<void>
}

export const useAi = create<AiState>()((set, get) => ({
  status: null,
  online: navigator.onLine,
  refresh: async () => {
    set({ status: await api.invoke('ai:status', undefined) })
  },
  setKey: async (key) => {
    const result = await api.invoke('ai:setKey', { key })
    if (result.ok) await get().refresh()
    return result
  },
  clearKey: async () => {
    await api.invoke('ai:clearKey', undefined)
    await get().refresh()
  }
}))

window.addEventListener('online', () => useAi.setState({ online: true }))
window.addEventListener('offline', () => useAi.setState({ online: false }))
```

### Task 5: The Writer

Notion's inline Writer: "Ask AI" first in the formatting toolbar, Cmd+J, an "Ask AI" slash item at the end of the menu, and Space on an empty line of text (whose hint becomes "Press ‘space’ for AI or ‘/’ for commands" while AI is ready).
The popup offers skills while its input is empty; skills stream plain text, typed instructions let Claude choose between editing and replying.
Edits stream into the page as a diff; Enter or Accept or a click away applies them, Undo or Cmd+Z removes them, Stop keeps what came, and follow-ups revise.
Explain and typed questions show the answer in the popup with Insert below.
Without a key the popup is a setup card with the privacy note.
The page is read-only while a change is pending, keeps the selection as a highlight, and never reports the change to the page editor, so it is never saved before Accept.

```tsx
function syncSelection(editor: AppEditor): void {
  const view = editor.prosemirrorView
  const dom = window.getSelection()
  if (!dom?.anchorNode || !dom.focusNode || !view.dom.contains(dom.anchorNode)) return
  try {
    const anchor = view.posAtDOM(dom.anchorNode, dom.anchorOffset)
    const head = view.posAtDOM(dom.focusNode, dom.focusOffset)
    const { selection } = view.state
    if (selection.anchor === anchor && selection.head === head) return
    editor.transact((tr) => tr.setSelection(TextSelection.create(tr.doc, anchor, head)))
  } catch {
    // The DOM selection is not in text; the editor's own selection stands.
  }
}

function newSession(editor: AppEditor): Session {
  const selectedBlocks = selectedBlockIds(editor)
  const textSelected = !editor.prosemirrorState.selection.empty
  const mark = selectedBlocks.length
    ? { selectedBlocks }
    : textSelected
      ? { selection: true as const }
      : { cursor: true as const }
  return {
    id: crypto.randomUUID(),
    selection: selectedBlocks.length > 0 || textSelected,
    selectedBlocks,
    markdown: pageMarkdown(editor, mark),
    answered: false
  }
}

/** Where the Writer sits: under the change, or under the selection or cursor. */
function anchorPos(editor: AppEditor): number {
  const state = editor.prosemirrorState
  const pending = pendingOf(state)
  if (pending?.rendered) {
    const { removed, added } = pendingRanges(pending)
    return Math.max(added.to, removed?.to ?? 0)
  }
  const ids = selectedBlockIds(editor)
  if (ids.length) {
    let end = state.selection.to
    state.doc.descendants((node, pos) => {
      if (node.type.name === 'blockContainer' && ids.includes(node.attrs.id))
        end = pos + node.nodeSize
      return true
    })
    return end
  }
  return state.selection.to
}
```

```ts
import { CURSOR, SELECTION_END, SELECTION_START } from '@shared/ai'
import type { Block } from '@shared/core/blocks'
import { blocksToMarkdown } from '@shared/core/serialize'

// eslint-disable-next-line @typescript-eslint/no-explicit-any
type AnyEditor = BlockNoteEditor<any, any, any>

const PLACEHOLDERS: Record<string, string> = {
  image: '[image]',
  video: '[video]',
  audio: '[audio]',
  file: '[file]',
  drawing: '[drawing]'
}

// Raw blocks are written out as they are, so the brackets are not escaped.
const marker = (markdown: string): Block => ({ type: 'raw', props: { markdown }, children: [] })

/** Media is named, never sent: its files stay on this Mac. */
function withoutMedia(blocks: Block[]): Block[] {
  return blocks.map((block) => {
    const name = PLACEHOLDERS[block.type]
    if (name) return { ...marker(name), id: block.id } as Block
    return { ...block, children: withoutMedia(block.children) } as Block
  })
}

function wrapBlocks(blocks: Block[], ids: Set<string>): Block[] {
  const first = blocks.findIndex((b) => ids.has(b.id!))
  if (first === -1)
    return blocks.map((b) => ({ ...b, children: wrapBlocks(b.children, ids) }) as Block)
  let last = first
  while (last + 1 < blocks.length && ids.has(blocks[last + 1].id!)) last++
  return [
    ...blocks.slice(0, first),
    marker(SELECTION_START),
    ...blocks.slice(first, last + 1),
    marker(SELECTION_END),
    ...blocks.slice(last + 1)
  ]
}

/**
 * The page as Markdown, with the text selection, the selected blocks or the cursor marked,
 * for Claude to read.
 */
export function pageMarkdown(
  editor: AnyEditor,
  mark: { selectedBlocks: string[] } | { cursor: true } | { selection: true }
): string {
  const state = editor.prosemirrorState
  const tr = state.tr
  if ('selection' in mark) {
    tr.insertText(SELECTION_END, state.selection.to)
    tr.insertText(SELECTION_START, state.selection.from)
  } else if ('cursor' in mark) {
    tr.insertText(CURSOR, state.selection.from)
  }
  const blocks: Block[] = []
  tr.doc.firstChild!.forEach((node) => {
    blocks.push(nodeToBlock(node, tr.doc) as unknown as Block)
  })
  const marked =
    'selectedBlocks' in mark ? wrapBlocks(blocks, new Set(mark.selectedBlocks)) : blocks
  return blocksToMarkdown(withoutMedia(marked))
}
```

### Task 6: Failures, offline, leaving, AI off, and the look

The cases a person meets on a bad day, each pinned by an e2e test: every error message (with the partial change kept after a dropped connection), offline greying, leaving the tab or quitting mid-answer, AI turned off in Settings, and the Writer and diff in light and dark.
Writing these tests found four bugs, fixed here:
- The SDK silently retried a 429 after its retry-after, so the Writer said nothing for 12 seconds; the client no longer retries.
- An error before any text rendered an empty change, which stayed struck through.
- The selected block showed as removed before any text came.
- In dark mode the popup barely stood out; it now has the 1px ring Notion gives raised surfaces.
